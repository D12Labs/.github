## D12Labs

An AI-native application studio in Aurora, Illinois. We build bespoke software for
founders, operators, and small-to-mid businesses — the systems a team runs on, not
templates adapted to fit.

Most of what we build is client work and lives in private repositories.

### How we build

Bun and TypeScript on Elysia, PostgreSQL with pgvector, Drizzle, Better Auth.
React and Vite on the front end, Tailwind and shadcn/ui. AI features go through
the Vercel AI SDK.

Delivery runs through a structured pipeline: every change is an issue, a branch, a
pull request and a green check, with the same guardrails applied across every
repository from one place.
